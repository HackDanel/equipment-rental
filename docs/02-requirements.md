# 2. Требования

## 2.1. Функциональные требования

### Клиент

| № | Требование | Где реализовано |
|---|---|---|
| FR-1 | Просмотр каталога с поиском по названию и описанию, фильтрами по направлению, категории, цене и свободности на даты, сортировкой | `/`, `catalog/views.py:index` |
| FR-2 | Карточка оборудования: фото, описание, цена за сутки, залог, скидки, календарь свободных экземпляров на 4 недели | `/equipment/<id>/` |
| FR-3 | Регистрация (логин, имя, фамилия, e-mail, телефон, пароль) и вход; самостоятельная регистрация всегда даёт роль «Клиент» | `/accounts/register/`, `/accounts/login/` |
| FR-4 | Бронирование на выбранные даты и количество с проверкой доступности и автоматическим расчётом стоимости до отправки формы | форма в карточке, `/api/quote/`, `bookings/services.py:create_booking` |
| FR-5 | Отслеживание статуса брони: ожидает подтверждения, забронировано, выдано, возвращено, просрочено, отменено, отклонено | `/my/`, `/bookings/<id>/` |
| FR-6 | История аренд и неоплаченные штрафы в личном кабинете | `/my/` |
| FR-7 | Отмена своей брони до выдачи | `/bookings/<id>/cancel/` |

### Менеджер

| № | Требование | Где реализовано |
|---|---|---|
| FR-8 | Очереди броней: новые, к выдаче, ожидаем возврат, просрочены, все (поиск по номеру, клиенту, оборудованию) | `/manager/` |
| FR-9 | Подтверждение или отклонение брони с причиной; при подтверждении повторно проверяется наличие исправных экземпляров | `confirm`, `reject` |
| FR-10 | Выдача: выбор конкретных экземпляров со склада, фиксация их состояния | `issue` |
| FR-11 | Приём: состояние каждого экземпляра, отметка «утерян», штраф за повреждение | `return_booking` |
| FR-12 | Автоматический расчёт штрафа за просрочку; штраф за утерю = стоимость возмещения; отметка об оплате | `late_fee`, `Fine` |
| FR-13 | Склад: просмотр экземпляров, отправка в ремонт и возврат из ремонта, смена состояния, журнал | `/stock/` |

### Администратор

| № | Требование | Где реализовано |
|---|---|---|
| FR-14 | Управление каталогом: позиции с фото, ценой, залогом, стоимостью возмещения; скрытие из каталога; категории | `/panel/equipment/`, `/panel/categories/` |
| FR-15 | Тарифы: скидки за срок, множитель штрафа за просрочку, максимальный срок аренды и горизонт бронирования | `/panel/tariffs/` |
| FR-16 | Управление сотрудниками (создание менеджеров и администраторов, блокировка) и клиентами (блокировка, перевод в менеджеры) | `/panel/staff/`, `/panel/users/` |
| FR-17 | Склад: поступление экземпляров, списание с указанием причины | `/stock/`, `add_units`, `write_off` |
| FR-18 | Статистика: выручка и штрафы по месяцам, брони по месяцам, топ оборудования, загрузка парка, брони по статусам, штрафы по видам, ключевые показатели | `/panel/` |

## 2.2. Нефункциональные требования

| № | Требование | Как выполнено |
|---|---|---|
| NFR-1 | Адаптивный и понятный интерфейс | Вёрстка от мобильной ширины, таблицы превращаются в карточки на узком экране, проверено на 375 px без горизонтальной прокрутки ([руководство](06-user-guide.md)) |
| NFR-2 | Валидация вводимых данных | Django-формы на сервере, ограничения целостности в БД (`CHECK`, `UNIQUE`, внешние ключи), подсказки в браузере (`min` у дат) |
| NFR-3 | Корректная обработка пересекающихся бронирований | Проверка доступности в форме и повторно в транзакции с блокировкой строки оборудования (`SELECT … FOR UPDATE`); тест с параллельными запросами ([тестирование](05-testing.md)) |
| NFR-4 | Время отклика страниц не более 2–3 секунд | Медиана 1–46 мс на сервере на демо-данных ([замеры](05-testing.md#53-время-отклика-nfr-4)) |
| NFR-5 | Безопасность | Пароли только в виде хеша PBKDF2, CSRF-защита форм, проверка роли на каждом представлении, защита от открытого редиректа, HTTPS, cookie `Secure` |
| NFR-6 | Сопровождаемость | Бизнес-правила в `services.py`, 91 автоматический тест, развёртывание одной командой, резервное копирование скриптом |
