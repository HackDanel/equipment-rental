# 5. Тестирование

## 5.1. Автоматические тесты

Тесты написаны на встроенном `django.test` и лежат в `apps/*/tests/`. Запуск:

```sh
.venv/bin/python manage.py test                            # SQLite
docker compose up -d && docker compose exec -u root web python manage.py test   # PostgreSQL
```

Результат на 29.10.2026: **91 тест, все проходят** на PostgreSQL 17; на SQLite 90 проходят, 1 (параллельные
брони) пропускается — блокировка строк есть только в PostgreSQL.

| Модуль | Файл | Тестов | Что проверяется |
|---|---|---|---|
| Доступность | `bookings/tests/test_availability.py` | 20 | пересечения дат и граничные случаи, количества, ремонт и списание, просрочка, границы сроков |
| Цены и штрафы | `bookings/tests/test_pricing.py` | 8 | стоимость, границы скидок, фиксация цены, штраф за просрочку и множитель |

## 5.2. Пересечение дат бронирования

Один экземпляр занят бронью на сутки **+5…+7** (обе даты включительно). Сколько свободно на запрошенный период:

| Запрос | Ситуация | Ожидается | Тест |
|---|---|---|---|
| +5…+7 | тот же период | 0 | `test_same_period_is_busy` |
| +3…+5 | конец запроса = начало брони | 0 | `test_end_touches_start_is_conflict` |
| +7…+9 | начало запроса = конец брони | 0 | `test_start_touches_end_is_conflict` |
| +2…+4 и +8…+10 | соседние дни | 1 | `test_adjacent_days_are_free` |
| +6…+6 и +1…+20 | вложенный и охватывающий период | 0 | `test_nested_and_covering_periods` |
| +5…+7 | бронь отменена / отклонена / возвращена | 1 | `test_finished_bookings_do_not_block` |
| +5…+7 | бронь новая / выдана | 0 | `test_new_and_issued_bookings_block` |
| +10…+12 | экземпляр в ремонте / списан | 0 | `test_units_in_repair_or_written_off_reduce_capacity` |
| сегодня…+1 | экземпляр не вернули в срок | 0 | `test_overdue_booking_keeps_unit_busy_today` |
| сумма | 3 экземпляра, брони на 2 + 1 шт. с частичным пересечением | 1 / 0 / 2 по дням | `test_sum_of_quantities` |
| параллельно | 6 одновременных броней последнего экземпляра | 1 успешна, 5 отклонены | `test_only_one_of_parallel_bookings_wins` |

## 5.3. Время отклика (NFR-4)

Замер 29.10.2026 на сервере b450: Gunicorn (3 воркера) + PostgreSQL 17, демо-набор (482 брони,
116 экземпляров), по 20 запросов на страницу. Публичные страницы — `curl` на `127.0.0.1:8210` (без Apache),
страницы сотрудников — Django test client внутри контейнера.

| Страница | Медиана | Максимум |
|---|---|---|
| `/` каталог | 10 мс | 36 мс |
| `/?date_from=…&date_to=…` каталог «свободно на даты» | 46 мс | 80 мс |
| `/equipment/<id>/` карточка с календарём | 12 мс | 22 мс |
| `/api/quote/` расчёт стоимости | 5 мс | 70 мс |
| `/manager/` рабочее место | 10 мс | 98 мс |
| `/manager/?tab=all` все брони | 15 мс | 17 мс |
| `/bookings/<id>/` карточка брони | 13 мс | 26 мс |
| `/stock/` склад | 10 мс | 13 мс |
| `/panel/` статистика | 19 мс | 24 мс |

Требование «не более 2–3 секунд» выполняется с большим запасом. Нагрузочное тестирование с сотнями
одновременных пользователей не проводилось.

## 5.6. Проверка API (Postman)

Коллекция [`docs/postman/rental.postman_collection.json`](postman/rental.postman_collection.json) — 5 запросов
к `/api/quote/` с автотестами `pm.test`. Даты считаются от текущего дня в pre-request скрипте, переменная
`base_url` по умолчанию указывает на опубликованную версию (для локальной — `http://127.0.0.1:8200`).

| Запрос | Ожидается | Фактический ответ 29.10.2026 |
|---|---|---|
| Расчёт на 7 суток, 1 шт. | 200, 7 суток, скидка, итог = цена × сутки × (1 − скидка) | 200, 7 сут., скидка 15 %, 7140,00 ₽ (1200 × 7 × 0,85) |
| 999 шт. | 200, `ok: false`, ошибка `quantity` | 200, «На эти даты свободно только 5 шт.» |
| Дата начала вчера | 400, ошибка `start_date` | 400, «Дата начала не может быть в прошлом.» |
| Дата «завтра» текстом, qty = 0 | 400, ошибки `start_date` и `quantity` | 400, обе ошибки |
| Оборудование 999999 | 404 | 404 |

Запуск в Postman: Import → файл коллекции → Run collection. Без интерфейса — `newman run
docs/postman/rental.postman_collection.json`. Фактические ответы в таблице получены теми же запросами через
`curl`; те же случаи покрыты автотестами `QuoteApiTests`.
