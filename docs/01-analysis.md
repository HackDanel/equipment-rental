# 1. Анализ предметной области

## 1.1. Как работает прокат оборудования

Пункт проката сдаёт посуточно три вида оборудования:

- **спортивное** — велосипеды, SUP-доски, каяки, лыжи, сноуборды;
- **туристическое** — палатки, тенты, спальники, коврики, горелки, рюкзаки, навигаторы;
- **строительное** — перфораторы, болгарки, шуруповёрты, плиткорезы, бетономешалки, леса, генераторы.

Одна позиция каталога (например, «Палатка трёхместная») — это несколько **физических экземпляров** с
инвентарными номерами. Клиент бронирует не конкретный экземпляр, а нужное количество позиции на даты;
конкретные экземпляры выбирает менеджер при выдаче.

Типовой жизненный цикл аренды:

```
Бронь → Подтверждение → Выдача (залог, осмотр) → Возврат (осмотр, штрафы) → Закрыта
                                    └→ Просрочка, если не вернули к дате окончания
```

| Роль | Что делает |
|---|---|
| Клиент | Выбирает оборудование и даты, бронирует, следит за статусом, получает и возвращает, платит штрафы |
| Менеджер пункта проката | Подтверждает брони, выдаёт экземпляры, принимает возврат, фиксирует состояние, начисляет штрафы, отправляет в ремонт |
| Администратор | Ведёт каталог, цены и скидки, склад и списание, сотрудников и клиентов, смотрит статистику |

Проблемы, которые возникают без информационной системы:

- **двойные брони**: два менеджера по телефону обещают последнюю палатку на пересекающиеся даты;
- непонятно, какой экземпляр у кого и в каком состоянии его выдали — спор о повреждениях не решить;
- просрочки замечают поздно, штраф считают вручную и по-разному;
- экземпляры «теряются» между складом, ремонтом и списанием;
- нет данных для решений: что приносит выручку, какое направление загружено, сколько штрафов не оплачено.

## 1.2. Обзор аналогов

| Решение | Тип | Сильные стороны | Ограничения для небольшого проката |
|---|---|---|---|
| Отечественные облачные CRM для прокатов | SaaS по подписке | брони, договоры, касса, склад | платная подписка, долгая настройка, интерфейс для сотрудников, а не клиентов |
| Booqable | зарубежный SaaS для аренды | онлайн-витрина, календарь доступности | платный, ориентирован на зарубежные платёжные системы, нет русской локализации документов |
| YCLIENTS и онлайн-записи | запись на услуги по времени | удобная запись клиента | рассчитаны на слоты времени мастера, а не на количество единиц на даты |
| Таблицы (Excel, Google Sheets) | универсальный инструмент | бесплатно, просто | нет проверки пересечений, ролей и истории, клиент не видит статус |

Вывод: небольшому прокату нужно лёгкое веб-приложение, где клиент сам видит свободное оборудование и
бронирует его, система не даёт пересечь брони сверх количества экземпляров, а менеджер ведёт выдачу, возврат
и штрафы с привязкой к конкретным инвентарным номерам. Такую систему и разрабатываем.

## 1.3. Ключевые правила предметной области

- Дата начала и окончания аренды **включительны**: аренда «с 5 по 7» — это 3 суток, и в день 7 экземпляр
  ещё занят. Следующая аренда того же экземпляра может начаться с 8-го.
- Свободно на даты = исправные экземпляры (на складе или выданы) минус сумма количеств активных броней,
  пересекающих эти даты. Экземпляры в ремонте и списанные не бронируются.
- Цена = цена за сутки × сутки × количество − скидка за срок (по тарифам). Цена фиксируется в момент брони.
- Просрочка: каждые сутки после даты окончания стоят цену суток × множитель (по умолчанию 1,5).
- Повреждение — штраф по решению менеджера (не больше стоимости возмещения), экземпляр уходит в ремонт.
  Утеря — штраф в размере стоимости возмещения, экземпляр списывается.

## 1.4. Границы проекта

Входит: каталог с фото, поиском и фильтрами (в том числе «свободно на даты»), регистрация и роли,
бронирование с проверкой доступности и расчётом стоимости, личный кабинет клиента, рабочее место менеджера
(подтверждение, выдача, приём, штрафы), учёт склада по экземплярам с журналом, ремонт и списание, панель
администратора (каталог, тарифы, сотрудники, клиенты), статистика с графиками, публикация на сервере.

Не входит (возможное развитие): онлайн-оплата и касса, договор аренды в PDF, SMS/e-mail-уведомления,
бронирование конкретного экземпляра, несколько пунктов проката.
